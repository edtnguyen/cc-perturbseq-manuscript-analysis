# Processed GEO datasets

Place `Hippo_timecourse_integrated.h5mu` and
`iPSC_K562_mixed_integrated.h5mu` here after downloading the submitted processed
data. Public GEO URLs are not yet configured. Do not commit these large objects
to Git; they are distributed by GEO. No original Split-pipe or Hippo source
folder is required for plotting from the integrated files.
